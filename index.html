Notation

1. Add Section

section: [length] [tempo] [key]

section: section name

length: total length in beats (default: 32)

tempo: section tempo in bpm (default: 120)

key: actual key of c4 (default: c4)

inherit: inherit last section settings if omitted

2. Add Track

- track: [instrument] [volume] [pan]

track: track name

instrument: inst name see reference (default: apiano)

volume: track volume from 0 to 1 (default: 1)

pan: track pan from -1 to 1 (default: 0)

solo: solo track by adding 's' to volume

3. Select Track

section.track: [offset]

section.track: track to write

offset: start time in beats (default: 0)

ahead: start before section head by negative offset

4. Write Rhythm

- [duration] [duration] ...

trigger: if first input is a number

duration: note duration in beats (default: 1)

measure: add measure line by "|"

5. Write Melody

- [pitch] [pitch] ...

trigger: if first input is a letter+number

pitch: pitch name see reference (default c4)

octave: inherit preceding octave if number omitted

chord: simultaneous multiple pitches if connected by "-"

voicing: choose nearest higher note if number omitted

percussion: percussion name see reference (default b)

rest: rest current note by "."

extend: extend preceding note by "-"

repeat: repeat preceding note by "="

measure: add measure line by "|"

6. Write Lyrics

- [text] [text] ...

trigger: if not writing rhythm or melody

rest: rest current note by "."

measure: add measure line by "|"

7. Write Comment

// [comment] ...
